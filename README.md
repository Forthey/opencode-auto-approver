# OpenCode Auto Approver

Плагин для OpenCode 2.1.0 проверяет shell-команды выбранным агентом до их выполнения. По умолчанию проверка отключена.

## Подключение

Установите зависимости в каталоге плагина с помощью `npm install`. Добавьте путь к каталогу плагина в `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "/absolute/path/to/opencode-auto-approver",
      "options": {
        "enabled": true,
        "agent": "reviewer",
        "allow": false,
        "ask": true,
        "fallback": "ask"
      }
    }
  ]
}
```

`agent` - идентификатор агента из OpenCode. `allow` и `ask` независимо включают проверку соответствующих решений разрешений. `fallback` определяет действие при отказе агента или ошибке: `ask` запрашивает подтверждение человека, `deny` запрещает команду. Использование агента расходует токены и передаёт ему команду и контекст сессии.

При ошибке в конфигурации OpenCode может не загрузить плагин. Проверьте загрузку плагина перед использованием авто-апрува.

В палитре команд TUI откройте `Configure auto approver`, чтобы выбрать агента и изменить настройки. Изменения сохраняются и имеют приоритет перед конфигом. Пункт `Reset to configuration` удаляет сохранённые изменения.

Явный `deny` всегда сохраняется: OpenCode не передаёт такие решения плагину. Для составной команды OpenCode передаёт общее решение для всех ресурсов, поэтому флаги `allow` и `ask` применяются к общему решению, а не к отдельным частям команды. Остальные инструменты плагин не проверяет.

## Проверка

Запустите `npm test` и `npm run typecheck`. Для работы с TUI необходим запущенный OpenCode с подключённым плагином и настроенным агентом с доступной моделью.
